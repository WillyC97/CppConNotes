# REST APIs

**Re**presentational **S**tate **T**ransfer

Benefits:
1. Simple and standardised
2. Scaleable and stateless
3. High performance (support caching)

REST APIs send a request and expect a response (Client - Server model)

For HTTP operations/Method:

* **C**reate --> POST
* **R**ead   --> GET
* **U**pdate --> PUT
* **D**elete --> DELETE

Inside the REQUEST:
* Operation - i.e the HTTP operations above
* End point/URL
* Headers
* Parameters

From the server you receive a RESPONSE:
* Typically in JSON format
